# cybersecurity-analysis-tool

This project helps users check basic computer security settings.

## Features
- Check Windows Firewall status
- Help identify basic security problems
- Keep track of cybersecurity improvements

## Tools
- Python
- GitHub
- Freshworks

## Purpose
This project was created for a school assignment to practice Git, GitHub, and issue tracking.

## Version Control

This project uses GitHub for version control.

- Main branch stores the production version.
- Development branch stores ongoing changes.
- Feature branches are used to add new features.
- Pull requests are used to merge changes.
